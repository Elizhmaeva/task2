# Поиск ассоциативных правил

Практическое задание по дисциплине «Интеллектуальный анализ данных».
Программа поиска частых наборов (алгоритм Apriori) доработана: по найденным
частым наборам она строит ассоциативные правила вида «антецедент → консеквент»
и для каждого правила выводит поддержку, достоверность и лифт.

## Состав каталога

| Файл | Назначение |
|---|---|
| `association_rules.py` | поиск ассоциативных правил, программа с интерфейсом командной строки |
| `apriori.py` | поиск частых наборов алгоритмом Apriori (из первого задания) |
| `experiments.py` | эксперименты с разными порогами достоверности и построение диаграмм |
| `baskets.csv` | набор данных: 7501 транзакция, 115 товаров |
| `results/support_selection.csv` | обоснование выбора порога поддержки |
| `results/experiments.csv` | сводная таблица экспериментов |
| `results/rules_XX.csv` | список правил для порога достоверности XX % |
| `results/time.png`, `results/rules_count.png` | диаграммы |

## Запуск

Нужен Python 3.8 или новее. Для `association_rules.py` и `apriori.py` сторонние
библиотеки не требуются, для `experiments.py` нужна библиотека matplotlib
(`pip install matplotlib`).

```
python association_rules.py baskets.csv 0.001 0.7 --order support
python association_rules.py baskets.csv 0.01 0.4 --order lex --output rules.csv
python experiments.py
```

Параметры `association_rules.py`:

- `dataset` — CSV-файл, в котором одна строка соответствует одной транзакции;
- `min_support` — порог поддержки, доля от 0 до 1 (0.001 соответствует 0,1 %);
- `min_confidence` — порог достоверности, доля от 0 до 1 (0.7 соответствует 70 %);
- `--order` — упорядочивание списка правил: `support` — по убыванию поддержки
  (по умолчанию), `lex` — лексикографическое;
- `--max-items` — наибольшее суммарное число объектов в антецеденте и
  консеквенте (по умолчанию 7);
- `--output` — необязательный CSV-файл для сохранения списка правил.
